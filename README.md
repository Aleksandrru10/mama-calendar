# Мой график — веб-версия

Офлайн-календарь смен, опубликованный на GitHub Pages. Графики, фотографии и выплаты хранятся в браузере устройства, а не в репозитории. Периодически сохраняйте JSON-копию через «Ещё» → «Резервная копия».

## Исправление 1.4.1

- Восстановлен русский текст HTML: при подготовке исходного Android-артефакта UTF-8-текст был ошибочно прочитан как Windows-1251 и снова сохранён в UTF-8. Ошибка содержалась в файле, а не в HTTP-заголовке.
- Исправлены не только видимые подписи, но и кириллические значения вариантов смен.
- Офлайн-кеш заменён на `my-schedule-mama-v2`. Удаляется только старый кеш этого приложения; `localStorage` и чужие кеши не очищаются.
- Для перехода с первой версии используйте прежний адрес с `?v=2`. Это позволяет обойти старый кеш HTML; данные остаются в том же origin.
- Новый `app.js?v=2` не смешивается со старым JavaScript из кеша v1. HTML и статические файлы теперь проверяются в сети, с офлайн-резервом.
- Регистрация worker вынесена из inline-скрипта; CSP разрешает только собственные worker, manifest и подключения.
- Удалена Android-ссылка обновления. Отсутствующее в веб-разметке необязательное поле ставки больше не вызывает ошибку при открытии сохранённого профиля и раздела выплат; существующая ставка в данных сохраняется.

## Проверка

`npm install`, затем `npm test`. Нужны Python, Git и Chrome. На Windows по умолчанию используется `C:/Program Files/Google/Chrome/Application/chrome.exe`; другой путь можно задать переменной `CHROME_PATH`.

Тест кодировки проверяет русский заголовок, подписи и значения смен. Браузерный тест сначала поднимает реальную старую версию из коммита `5a928a6`, создаёт тестовый график и кеш v1, затем обновляет приложение. Проверяются точное сохранение localStorage при обновлении, сохранность чужого кеша, вкладки на ширинах 320/390/430, плановые дни выплат, исключение дня и офлайн-перезапуск. Проверяются ошибки JavaScript и CSP.

Скриншоты и данные тестового браузера не относятся к пользовательскому профилю. Проверка в Chrome с мобильным viewport не заменяет проверку на физическом iPhone.

## Правило следующего релиза

Проверять видимый русский текст и значения полей, а не только HTTP 200 или наличие `charset=utf-8`. При изменении файлов повышать версию кеша и версию изменённых entrypoint-ресурсов; прогонять тест перехода с тёплого старого кеша. Не очищать пользовательские данные ради обновления интерфейса.
